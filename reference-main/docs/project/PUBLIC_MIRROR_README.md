# quantoniumos — Public Research Mirror

**This is a read-only mirror.** Active development happens in a private repository.

---

## What This Repository Contains

This mirror publishes the mathematical foundations and research positioning of the Resonant Fourier Transform (RFT) — a unitary transform on ℂ^N using golden-ratio frequency spacing.

Included:
- Honest classification of what is proved, empirical, and open
- Explicit non-claims and known limitations
- Open research problems
- License and patent notice

## What This Repository Does Not Contain

This mirror intentionally excludes:
- Implementation source code
- Benchmarks, tests, and experimental results
- Patent prosecution materials
- Internal architecture documentation
- Hardware designs
- Build system and CI configuration

These materials are maintained privately and are available for review on request.
